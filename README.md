# Book API

A production-like REST API infrastructure built with Go and PostgreSQL, featuring Docker, Nginx, CI/CD, monitoring, centralized logging, and alerting.

```text
                         ┌───────────────┐

                                 ▼
                         ┌───────────────┐
                         │     Nginx     │

                                 │
                                 ▼
                         ┌───────────────┐
                         │    Book API   │
                         │      Go       │
                         └───────┬───────┘
                                 │

        │ Promtail ──► Loki ──► Grafana           │
        │ Prometheus ──► Alertmanager              │
        └─────────────────────────────────────────┘
```

## Project Goal

This repository demonstrates the evolution of a backend service into a production-like infrastructure.

The project gradually grows from a simple REST API into an automated and observable platform featuring monitoring, centralized logging, infrastructure automation, Kubernetes, and GitOps.

## Monitoring

The application exposes Prometheus metrics through:

```text
/metrics
```

Application metrics include:

- HTTP requests
- HTTP errors
- HTTP request duration
- Books created
- Books returned
- Database queries

Grafana provides separate dashboards for:

- Application
- Server

Loki and Promtail provide centralized collection and visualization of Docker container logs.

Alertmanager handles alerts generated by Prometheus.

## Getting Started

1. Clone the repository.

2. Copy the environment template:

```bash
cp .env.example .env
```

3. Start the application:

```bash
docker compose up --build
```

The API will be available at:

```text
http://localhost
```

Grafana:

```text
http://localhost:3000
```

Prometheus:

```text
http://localhost:9090
```

Alertmanager:

```text
http://localhost:9093
```

## Environment Variables

The project uses the following environment variables:

| Variable      | Description             |
| ------------- | ----------------------- |
| `DB_HOST`     | PostgreSQL host         |
| `DB_PORT`     | PostgreSQL port         |
| `DB_USER`     | PostgreSQL username     |
| `DB_PASSWORD` | PostgreSQL password     |
| `DB_NAME`     | PostgreSQL database name|

See `.env.example` for default values.
